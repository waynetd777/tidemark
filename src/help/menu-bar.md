## <!-- mac -->Menu bar<!-- /mac --><!-- github --> (Mac) or <!-- /github --><!-- windows -->Notification area<!-- /windows --><!-- github --> (Windows)<!-- /github -->

Tidemark keeps recording in the <!-- mac -->menu bar<!-- /mac --><!-- github --> (Mac) or <!-- /github --><!-- windows -->notification area<!-- /windows --><!-- github --> (Windows)<!-- /github --> after you close its window.

- <!-- mac -->Closing the window also takes Tidemark out of the Dock.<!-- /mac --><!-- github --> On Windows: <!-- /github --><!-- windows -->There is no Dock: with the window closed, Tidemark is only in the notification area, by the clock.<!-- /windows -->
- The icon gets <!-- mac -->a mark<!-- /mac --><!-- github --> (Mac) or <!-- /github --><!-- windows -->an amber dot<!-- /windows --><!-- github --> (Windows)<!-- /github --> when something needs attention: memory running high, the CPU busy, swap growing, a low battery, a nearly full disk.
- Click it for a small window<!-- windows --> (above the icon when the taskbar is at the foot of the screen)<!-- /windows -->: a sentence on how the computer is doing, and CPU, memory, network download, energy and disk I/O, each with a meter of how full it is now and a line for the last hour. Beside each: today's high for CPU and memory, the upload for network, the battery and time left for energy, and the reads and writes for the disk.<!-- windows --> A PC with no battery has no energy row.<!-- /windows -->
- Click a measure to open Recent at its tab.
- Below them: the apps using the most of whatever is tightest right now (the measure needing attention, or else whichever of CPU and memory is nearer its limit), which open Now's lists of them, and a line about the week when there is something to say (an app holding much of your memory, or the disk growing by a gigabyte or more).
- When something needs attention, the main action takes you to it (Show what's using memory, say, which opens Now at those lists, ⌘1).
- Then **Open Tidemark** (⌘O), **Settings** (⌘,)<!-- windows -->, **Tidemark Help** (⌘?), **Check for Updates…**<!-- /windows --><!-- github --> (those two on Windows only, which has no app menu)<!-- /github --> and **Quit** (⌘Q). ⌘1, ⌘2 and ⌘4 open Now, Recent and Disk Map; Esc closes the window.
- Quitting stops recording, unless the background helper is on.
