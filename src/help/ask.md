## Ask

**Ask** (⌘K) is a chat with an AI about your Mac, using what Tidemark knows.

- Ask why the Mac was slow on Wednesday, or where space can be freed safely. Start from a suggested question or type your own; follow-ups continue the conversation.
- It is given the folder on screen and its biggest folders, what grew this week, and the performance record: CPU, GPU, memory and its split, network, energy, today's highs, the week's tidemarks, incidents, crashes, and the apps that used the most.
- An **Ask** button sits beside each incident and crash in This week's tidemarks on Now, and on any chart flagged amber or red. It opens Ask with a question and that thing's details attached: an incident's apps at its peak, a crash's reports (the exception and the crashed thread's stack), a chart's figures and what each app is using now. **Remove** sends the question without them.
- It runs through an AI command-line tool already signed in on this Mac: Claude Code, Codex, Antigravity or GitHub Copilot. No key is set up in the app; with none installed, Ask is disabled and says why.
- The model menu lists every model those tools offer. Claude Opus is the default; your choice is remembered.
- The AI sees names, sizes, paths and figures, and a crash report's summary when you ask about a crash. It can't read your files, and Tidemark changes nothing: it advises, you act.
- **Copy** copies an answer as text and formatted text. **New chat** starts over.
