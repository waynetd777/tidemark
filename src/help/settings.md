## Settings

A few choices; everything else looks after itself.

- **Keep recording when quit**: a small background helper (Tidemark's own program, no window) records while the app is quit and starts when you <!-- mac -->log in<!-- /mac --><!-- github --> (Mac) or <!-- /github --><!-- windows -->sign in<!-- /windows --><!-- github --> (Windows)<!-- /github -->. <!-- mac -->macOS lists it as "Tidemark" under System Settings › General › Login Items › Allow in the Background<!-- /mac --><!-- github -->; <!-- /github --><!-- windows -->Windows lists it as "Tidemark Helper" under Windows Settings › Apps › Startup<!-- /windows -->; switched off there, Settings says so, and switching it back on there is the way to allow it again. When both run, one records and the other waits to take over; when it's the helper, the app shows what it records.<!-- mac --> If it's quit, it starts again within 5 minutes.<!-- /mac --> If it doesn't seem to record, its messages are in helper.log in Tidemark's folder (below).
- **Open at Login**: starts Tidemark in the <!-- mac -->menu bar<!-- /mac --><!-- github --> (Mac) or <!-- /github --><!-- windows -->notification area<!-- /windows --><!-- github --> (Windows)<!-- /github --> when you <!-- mac -->log in<!-- /mac --><!-- github --> or <!-- /github --><!-- windows -->sign in<!-- /windows -->. <!-- mac -->It's the same switch as System Settings › General › Login Items<!-- /mac --><!-- github -->; <!-- /github --><!-- windows -->Windows lists it as "Tidemark" under Windows Settings › Apps › Startup<!-- /windows -->. It works in the installed app only.
- **Keep every minute for**: 14, 7 or 3 days, the detail Recent shows. Shortening it forgets older minutes at once; the year of daily rows (for Trends) and of daily disk totals is kept either way.
- **Scan the disk**: **Daily** (the default) scans once a day when the computer has been idle for 5 minutes and is on power; once the last scan is two days old, it scans when idle on battery too. **Hourly** scans every hour, idle or not, on power or not, and costs some battery. **Off** never scans by itself, not even at launch: only when you press Reload.
- **Appearance**: **Match <!-- mac -->macOS<!-- /mac --><!-- github --> (or <!-- /github --><!-- windows -->Windows<!-- /windows --><!-- github -->)<!-- /github -->** (the default), **Light** or **Dark**. The <!-- mac -->menu-bar<!-- /mac --><!-- github --> or <!-- /github --><!-- windows -->notification-area<!-- /windows --> window follows.
- **About** shows the version; **Website** opens tidemark.davies.co.za.<!-- mac --> Tidemark › About Tidemark shows it too, as a link, and Help › Tidemark Website opens it.<!-- /mac --><!-- windows --> On Windows, **Check for Updates…** sits beside them.<!-- /windows -->
- **Updates**: Tidemark checks for a new version shortly after it opens and then once a day, and asks before installing it, with the release's notes: **Install and Restart**, **Later** (Esc) or **Skip This Version**. <!-- mac -->Tidemark › Check for Updates…<!-- /mac --><!-- github --> on a Mac, or <!-- /github --><!-- windows -->**Check for Updates…** in Settings or the notification-area window<!-- /windows --><!-- github --> on Windows,<!-- /github --> checks now. A new version found in the background waits until you next bring Tidemark's window forward, and one won't install during a scan or while Ask is answering. <!-- mac -->Installing shows the download's progress, then restarts Tidemark, and the background helper with it.<!-- /mac --><!-- windows -->Installing on Windows shows the download's progress, installs quietly and reopens Tidemark.<!-- /windows -->
- The foot shows how much space the history takes and where<!-- mac -->, and whether Tidemark has Full Disk Access<!-- /mac -->.

## History

Everything Tidemark remembers stays on this computer, in <!-- mac -->~/Library/Application Support/Tidemark<!-- /mac --><!-- github --> on a Mac or <!-- /github --><!-- windows -->%LOCALAPPDATA%\com.wayned.tidemark<!-- /windows --><!-- github --> on Windows<!-- /github -->: the history in history.sqlite, the last scan of each folder you scanned (in scans), your choices in settings.json, and the background helper's messages in helper.log (emptied once it passes 1 MB). Small files beside them (the .lock files, the live.sock socket and others) let the app and the helper share the work. Ask runs its AI tool in an empty folder of its own, <!-- mac -->~/Library/Application Support/com.wayned.tidemark<!-- /mac --><!-- github --> on a Mac or <!-- /github --><!-- windows -->%APPDATA%\com.wayned.tidemark<!-- /windows --><!-- github --> on Windows<!-- /github -->.

| What | Kept for |
|---|---|
| Every minute's CPU, GPU, memory and its split, swap, pressure, disk, network, power and battery, with the busiest apps | The history setting (14 days at most) |
| Incidents, sleeps, crashes and hangs | The same |
| The disk's used space hourly, and folders of 100 MB or more from each scan (the last scan of each day once it's a day old) | The same |
| One row a day of every measure (averages, peaks, totals, incidents and crashes, the busiest apps), for Trends | A year, whatever the setting |
| One row a day of disk space and its biggest folders | A year, whatever the setting |

- Tidemark records while it runs. Closing the window keeps it running in the <!-- mac -->menu bar<!-- /mac --><!-- github --> (Mac) or <!-- /github --><!-- windows -->notification area<!-- /windows --><!-- github --> (Windows)<!-- /github -->.
- **Keep recording when quit** (Settings) records even while the app is quit.<!-- windows -->
- Uninstalling Tidemark in Windows Settings › Apps keeps the history, unless you tick **Delete the application data**.<!-- /windows -->
